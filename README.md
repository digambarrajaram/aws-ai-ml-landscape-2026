# AWS AI/ML Landscape 2026

## Three-Tier Architecture

### **Tier 1 — Custom ML Models**
- **Amazon SageMaker** - Complete ML lifecycle
- **SageMaker Studio** - ML development environment
- **SageMaker Training** - Model training
- **SageMaker Inference** - Predictions

### **Tier 2 — Foundation Models**
- **Amazon Bedrock** - Foundation models API
- **Amazon Q** - AI assistant
- **Amazon Q Developer** - AI code generation
- **Amazon Titan** - AWS foundation models
- **Claude (via Bedrock)** - Advanced reasoning

### **Tier 3 — AI APIs**
- **Amazon Rekognition** - Computer vision
- **Amazon Textract** - Document analysis
- **Amazon Comprehend** - Natural language processing
- **Amazon Polly** - Text-to-speech
- **Amazon Transcribe** - Speech-to-text
- **Amazon Translate** - Language translation

## Getting Started

- **Beginner** → Tier 3 APIs
- **Intermediate** → SageMaker built-ins or Foundation Models
- **Advanced** → Custom ML models
